ZImager 1.8.3

ZImager is the photo editor and the library in one app.
Disk opens folders on this Mac. Server talks to a helper on a Synology.

This disk image contains ZImager.app and this README. It does not
include the helper.

What 1.8.3 changes
------------------
Folder view, on Disk and on Server, can join two still photos into one
TIFF. Select exactly two photos in the same folder. The panel is
"Merge two photos", under Move selected files. Choose Horizontal or
Vertical. The first photo you click is the left side, or the top. The
second is the right side, or the bottom. A sideways pair stays
sideways. Preview starts the two photos flush, edge to edge, so you
line up the seam yourself.

Preview opens over the folder. Arrow keys move the second photo one
pixel at a time: left, right, up, and down. Shift-arrow is also one
pixel. Click zooms in at the pointer. Option-click zooms out, and it
stops when the whole join fits. Hold Space and drag to move the whole
picture. The two photos keep the placement you set. Fit shows the whole
join. 100% shows one image pixel per point, centered on the seam, and
clicking 100% again recenters. Changing Horizontal or Vertical returns
to a flush join. Cancel closes the preview and writes nothing.

Merge writes an 8-bit TIFF in the same folder and leaves the two
originals. The name is the first file's name, a hyphen, and the second
file's name, with .tiff. If that name is taken, the file is name-2.tiff,
then name-3, up through name-999. An overlap is blended. A gap along
the join stays black. A slide past the edge fills the clear band from
the nearest pixels of the photo.

After the merge is accepted, right-click a file in Folder view and
choose Rename. Rename is hidden while the preview is up. The file stays
in that folder. A name that is already there is refused. An empty name,
".", "..", a slash, a colon, or a name the file system will not take is
refused. A change of capitalization only is allowed.

Disk Folder view has the same Move panel as Server. It sits between
Date and Merge. The title is "Move selected files to specified Folder".
The checkbox "Sub-folder of this folder" starts unchecked. Unchecked,
the named folder is created under the folder you opened, the root of
the tree. Checked, it is created inside the folder on screen. A file
already in the destination stays where it is. Two files with the same
name become name-2. The names _Removed, _Duplicates, and _Review are
refused. The folder list reloads, and a new folder shows in the left
tree. This move does not use the helper.

The Events button and the Reorganize button are hidden. Those tools
are not ready. Geometry keystone is unchanged. Vertical still changes
the top and bottom edges. Horizontal still changes the left and right
edges.

The helper is unchanged. This disk image does not include it.

1.8.2, 1.8.1, and 1.8.0 are still in this app: Move to Folder on
Server, Delete ALL on Photos/_Removed, previews for the rest of the
open folder, Red Eye, a folder name filter, pages past 200 photos,
later-page previews, fast Spot and Scratch repair, Flatten, and Rescan.
1.7.2, 1.7.1, 1.7.0, and 1.6.0 are still here too: in-app video with
graded export, Horizon, stacked spot repairs, ZImager as the only app,
Folder View and Edit View, arrow keys between photos, folder Export and
Print, Copy settings and Paste settings, Tone Auto and Reset, Spectrum,
Remove from library into Photos/_Removed, and Set date into the date
folder.

This build is Apple Silicon. It runs on macOS 26. It does not require
macOS 27.

Do not use Reorganize, Review, or Duplicates
---------------------------------------------
Those three do not work yet. Using them can lose photos.
The Events and Reorganize buttons are hidden.
Leave Reorganize, Review, and Duplicates alone.
Do not press Start, Pause, Continue, Find duplicates, or Delete all duplicates.

Install
-------
1. Open this disk image.
2. Drag ZImager.app into Applications.
3. Follow Approval below once.

Approval
--------
ZImager is built by Tom Zimmer on his Mac using Apple's development tools.
It is not notarized for distribution. macOS asks you to approve it once
before it will run.

1. Double-click ZImager.app.
2. macOS says Apple could not verify that ZImager is free of malware.
   Close that dialog.
3. Open System Settings → Privacy & Security.
4. Scroll to Security until you see that ZImager was blocked.
5. Click Open Anyway.
6. Confirm Open Anyway again if asked, then enter your password.

After that, double-click ZImager and it will run.

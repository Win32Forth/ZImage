ZImager 1.8.5

ZImager is the photo editor and the library in one app.
Disk opens folders on this Mac. Server talks to a helper on a Synology.

This disk image contains ZImager.app and this README. It does not
include the helper.

What 1.8.5 changes
------------------
Dragging the photograph moves it. The scroll wheel zooms in and out
around the pointer. Scroll up zooms in. A trackpad pinch still zooms.

Curve sits between Tone and Color. The graph shows the photograph's
brightness. RGB shapes the whole picture. Red, Green, and Blue shape
one channel after that. Linear, Matte, Film Moody, Punch, and Lo-fi
set the RGB curve. Drag a handle. Click the curve to add a point, up
to eight. Double-click a middle handle to remove it. Double-click an
end to put that corner back.

Vignette sits under Touchup. Amount, Midpoint, Roundness, Feather, X,
and Y shape the edges. Negative Amount darkens them. Positive Amount
lightens them. Positive X moves the clear center right. Positive Y
moves it up.

Flatten asks before it writes. Duplicate, on that dialog, writes a
flattened TIFF next to the photograph. The name gains -2, then -3
when that name is taken. The photograph and its edits stay as they
are.

Folder view folds each panel on the right from an arrow at the end of
its title. Preview is the word above the picture. Build previews sits
under Merge two photos, on Disk and on Server Photos. It builds a
preview for each photo in the open folder that does not already have
one. Videos are skipped. Clear the name filter first. Disk keeps
those previews in its temporary cache. Server stores them through
the helper.

Sigma X3F files appear in the folder grid. Opening one develops the
sensor image on this Mac and edits that picture. Export can write it
as a TIFF or a DNG. The color is the bundled converter's sRGB, not
Sigma Photo Pro. If that development cannot run, ZImager opens the
embedded preview and says so. The helper stores that embedded preview
and does not develop the sensor. X3I files are not opened.

Right-click Rename of a file under Photos keeps the same catalog id.
Photos/_Removed, Photos/_Duplicates, and Photos/_Review keep their
names. The helper on the NAS already has that route and the X3F
preview. This disk image does not include the helper. Stop the DSM
task before you replace the binary.

1.8.4, 1.8.3, 1.8.2, 1.8.1, and 1.8.0 are still in this app: folder
rename, Organize, Clean, rotation that keeps repairs in place,
previews off the main thread, Merge two photos, Rename a file, Move
to Folder on Disk and on Server, Delete ALL on Photos/_Removed,
previews for the rest of the open folder, Red Eye, a folder name
filter, pages past 200 photos, later-page previews, fast Spot and
Scratch repair, Flatten, and Rescan. 1.7.2, 1.7.1, 1.7.0, and 1.6.0
are still here too: in-app video with graded export, Horizon, stacked
spot repairs, ZImager as the only app, Folder View and Edit View,
arrow keys between photos, folder Export and Print, Copy settings and
Paste settings, Tone Auto and Reset, Spectrum, Remove from library
into Photos/_Removed, and Set date into the date folder.

This build is Apple Silicon. It runs on macOS 26. It does not require
macOS 27.

Do not use Reorganize, Review, or Duplicates
---------------------------------------------
Those three do not work yet. Using them can lose photos.
The Events and Reorganize buttons are hidden.
Leave Reorganize, Review, and Duplicates alone.
Do not press Start, Pause, Continue, Find duplicates, or Delete all duplicates.

Install
-------
1. Open this disk image.
2. Drag ZImager.app into Applications.
3. Follow Approval below once.

Approval
--------
ZImager is built by Tom Zimmer on his Mac using Apple's development tools.
It is not notarized for distribution. macOS asks you to approve it once
before it will run.

1. Double-click ZImager.app.
2. macOS says Apple could not verify that ZImager is free of malware.
   Close that dialog.
3. Open System Settings → Privacy & Security.
4. Scroll to Security until you see that ZImager was blocked.
5. Click Open Anyway.
6. Confirm Open Anyway again if asked, then enter your password.

After that, double-click ZImager and it will run.
